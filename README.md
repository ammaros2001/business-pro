# نظام إدارة المشاريع والتجارة الإلكترونية المتكامل (Business Hub SPA) 🚀
### نظام محاسبي وإداري سحابي متكامل باللون الأسود والأخضر الزمردي (Dark Emerald Theme)

---

## 🌟 نظرة عامة (Overview)
نظام وتطبيق ويب تقدمي (Single Page Application - SPA) مصمم بالكامل باللغة العربية مع دعم RTL وتصميم عصري متجاوب يدعم الهواتف الذكية والحواسيب اللوحية وشاشات سطح المكتب.
يتيح لك النظام إدارة ومتابعة عدة مشاريع تجارية (بزنسات ومتاجر إلكترونية) في وقت واحد بدقة محاسبية متقدمة تمنع الازدواجية المالية وتفصل بدقة بين رأس المال وتكلفة البضاعة المباعة (COGS) والمصروفات التشغيلية وصافي الأرباح.

---

## 🎨 الهوية البصرية والتصميم (Black & Emerald Theme)
- **الخلفيات:** أسود كربوني داكن وأنيق (`#070a08` - `#141e19`).
- **اللمسات البصرية:** أخضر زمردي فاخر (`#10b981`) وأخضر نيون متوهج (`#00ff88`).
- **المؤشرات المالية:** تدرجات لونية ديناميكية للأرباح والديون ونسب الإنجاز.
- **الخطوط:** خط `Cairo` العربي من Google Fonts لوضوح فائق وقراءة مريحة.

## ⚡ الميزات والوحدات الرئيسية (Core Modules)

### 1. لوحة التحكم والإحصائيات الذكية (Dashboard)
- **6 بطاقات إحصائية رئيسية حية:**
  1. **إجمالي رأس المال المستثمر (د.ل):** محسوب لجميع المشاريع النشطة.
  2. **إجمالي المبيعات المحققة:** مع بيان النقد المحصل فعلياً.
  3. **المصروفات التشغيلية:** مجموع مصاريف التسويق، التوصيل، والتغليف.
  4. **صافي الأرباح المحققة:** مع مؤشر لوني ذكي ونسبة هامش الربح (Profit Margin %).
  5. **قيمة المخزون المتبقي:** محسوبة بدقة على أساس تكلفة القطعة الأصلية.
  6. **ديون الزبائن المستحقة:** لمتابعة مبيعات الأجل والمستحقات المعلقة.
- **رسوم بيانية تفاعلية (Chart.js):**
  - مسار المبيعات الشهري مقارنةً بتكلفة البضاعة المباعة (COGS) والأرباح.
  - المخطط الدائري لتوزيع المصروفات حسب الفئات.
- شريط تقدم مباشر لمعدل تصريف مخزون كل مشروع وجدول أحدث عمليات البيع.

### 2. إدارة ومتابعة البزنسات (Active Businesses)
- بطاقات تفاعلية أنيقة لكل مشروع توضح:
  - صورة المنتج، بلد الاستيراد (الصين / ليبيا / أخرى).
  - رأس المال، متوسط تكلفة القطعة الواحدة، إجمالي المبيعات، وصافي الربح.
  - شريط تقدم استهلاك المخزون (المباع / المتبقي / قيمة المتبقي في المستودع).
- **نافذة منبثقة تفصيلية لكل مشروع (Business Detail Modal):**
  - مؤشرات مالية شاملة.
  - جدول مبيعات المشروع مع الفواتير.
  - جدول مصروفات المشروع المباشرة.
  - أزرار سريعة للبيع المباشر، التعديل، الأرشفة، أو الحذف.

### 3. نموذج إضافة / تعديل مشروع متقدم (Add / Edit Business)
- **المعلومات الأساسية:** اسم البزنس، اسم المنتج، بلد الشراء، التاريخ، عدد القطع، وصف وصورة المنتج (رفع ملف أو رابط مباشر).
- **نظام العملة المرن:**
  - بالدينار الليبي فقط (د.ل).
  - أو بالدولار ($) مع سعر الصرف، مع حساب وتوضيح المعادل بالدينار لحظياً.
- **حساب تكاليف الشحن المتقدم:**
  - **شحن بحري 🚢:** إدخال مساحة الشحنة (CBM / م³) مع سعر المتر المكعب.
  - **شحن جوي ✈️:** إدخال وزن الشحنة (كجم / kg) مع سعر الكيلوغرام.
  - خيار عملة الشحن (دينار أو دولار مع سعر صرف الشحن).
  - حقل تعديل يدوي مباشر لتكلفة الشحن بالدينار.
- **التكاليف الإضافية غير المحدودة:** إضافة وحذف بنود تكلفة إضافية ديناميكية (عمالة، تغليف، تخليص، إلخ).
- **الإعلانات التأسيسية:** خيار تضمين ميزانية الإعلانات الأولية ضمن رأس المال التأسيسي.
- **صندوق الملخص المالي الحي (Live Summary Box):**
  - حساب فوري أثناء الكتابة لتكلفة الشراء، الشحن، التكاليف الإضافية، إجمالي رأس المال المستثمر، ومتوسط تكلفة القطعة الواحدة (`Unit Cost = Capital ÷ Quantity`).

### 4. إدارة المبيعات والفوترة (Sales & Invoicing)
- تسجيل عملية بيع مرتبطة بمشروع ومراقبة فورية للمخزون المتاح لمنع البيع بكمية تفوق المخزون.
- إدخال الزبون، الهاتف، الكمية، سعر البيع، الخصم الممنوح، مصاريف البيع المباشرة (مثل عمولة التوصيل)، والمبلغ المدفوع.
- تصنيف تلقائي لحالة الدفع: **(مدفوع بالكامل 🟢 / دفع جزئي 🟡 / غير مدفوع بالأجل 🔴)** مع حساب المبلغ المتبقي على الزبون.
- نافذة تحصيل الدفعات وتسديد الديون بنقرة زر.
- نافذة توليد وطباعة إيصال وفاتورة بيع مصغرة جاهزة للطباعة.

### 5. إدارة المصروفات التشغيلية (Expenses)
- تصنيف المصروفات: إعلانات وحملات ممولة، تغليف وكراتين، شحن وتوصيل، مرجوعات وتوالف، رواتب وعمالة، أو أخرى.
- ربط المصروف بمشروع محدد أو اعتباره مصروفاً عاماً مشتركاً.
- دعم العملات (دينار أو دولار مع سعر الصرف).

### 6. التقارير المالية والتحليل الشامل (Reports)
- جدول مالي مقارن شامل لجميع المشاريع: رأس المال، المبيعات، تكلفة المباع COGS، المصروفات، صافي الأرباح، نسبة العائد ROI، وهامش الربح.
- كشف الديون والمستحقات الآجلة على الزبائن مع أزرار التحصيل الفوري.
- دعم كامل لتصدير التقارير إلى ملف **Excel / CSV**.
- تصميم جاهز للطباعة المباشرة (`window.print`).

### 7. أرشيف المشاريع المغلقة (Archive)
- حفظ المشاريع المنتهية مع سجلاتها وإحصائياتها النهائية، مع إمكانية إعادة التنشيط في أي وقت.

### 8. السحابة والعمل بدون إنترنت (Cloud & Offline)
- **الوضع المحلي الافتراضي (Offline Mode):** يعمل التطبيق بنسبة 100% فور فتحه على أي متصفح دون الحاجة لأي إعدادات، ويحفظ البيانات في `LocalStorage`.
- **المزامنة السحابية عبر Firebase:**
  - دعم Firebase Realtime Database لمزامنة التغييرات لحظياً عبر جميع الأجهزة.
  - دعم Firebase Authentication (تسجيل بالبريد وكلمة المرور وحساب Google).
- **النسخ الاحتياطي:** تنزيل واستيراد ملفات نسخة احتياطية كاملة بصيغة JSON.
- **بيانات تجريبية جاهزة (Demo Data):** شحن واستكشاف بيانات جاهزة بكبسة زر.

## 🛠️ كيفية التشغيل والاستخدام (How to Run)
1. افتح الملف `index.html` في أي متصفح حديث (Google Chrome, Microsoft Edge, Safari, Firefox).
2. سيعمل التطبيق مباشرة محملاً ببيانات تجريبية ذكية لتجربة كافة الشاشات والرسوم البيانية فورياً.
3. لتشغيل المزامنة السحابية، توجه إلى قسم **الإعدادات والسحابة** وأدخل بيانات مشروع Firebase الخاص بك.
